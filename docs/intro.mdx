# Start Here

Flow Steward is a self-hosted AI workflow automation platform. Compose phases
and steps, connect external systems through extensions, and run controlled
workflows with human approval gates. Core is not a software-delivery or
application-code generation engine.

The application combines an operator web UI, workflow execution, project
knowledge, agent/tool registries, extension runtimes, and operational
controls for long-running AI-assisted work.

## Documentation map

- [Start Here](intro) gives a short product overview, role paths, concepts, and
  first-run guidance.
- [User Guide](user/dashboard) explains the product through the UI: dashboard,
  workspaces, jobs, workflows, agents, MCP catalogs, datasets, extensions, and
  lifecycle controls.
- [Admin & Operations](admin/events-and-redrive) covers users, roles, providers,
  policy, redaction, events, audit evidence, queues, retries, and monitoring.
- [Deploy & Run](deploy/deployment-checklist) covers install, update,
  environment configuration, backups, storage, observability, rollback, and
  deployment troubleshooting.
- [Integrations & Extensions](integrations/built-in-mcp-quick-start) covers
  incoming webhooks, external MCP catalogs, built-in MCP client setup, data
  connections, and extension authoring.
- [Developer Platform](developer/local-development) explains how to work on the
  application codebase, runtime, frontend, database, tests, and internals.
- [API & Reference](reference/cli) keeps command, MCP, API, installer, workflow,
  environment, configuration, and upgrade details in stable lookup pages.
